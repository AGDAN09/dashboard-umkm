# Dashboard UMKM

Dashboard admin sederhana untuk membantu pemilik usaha kecil mengelola produk, stok, dan pesanan.

## Fitur
- Ringkasan omzet, pesanan baru, dan stok menipis
- Kelola produk: tambah, cari, ubah stok, hapus
- Kelola pesanan: filter dan ubah status
- Data tersimpan otomatis di localStorage
- Tampilan responsif (sidebar di desktop, menu bawah di HP)

## Teknologi
Next.js 14 (App Router), TypeScript, Tailwind CSS, Lucide React

## Menjalankan
    npm install
    npm run dev

Buka http://localhost:3000
